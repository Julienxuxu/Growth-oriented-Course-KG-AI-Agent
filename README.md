生长型课程知识图谱 AI 助手 (Growth-oriented Course KG AI Agent)

系统概述

本系统是一个基于 Gradio 的 AI Agent，旨在辅助教师将课程知识结构从最初的“总体蓝图”逐步细化并“生长”为完整的课程体系。

核心功能

•
总体蓝图生成：输入课程名称或描述，AI 自动生成章节级的初步结构。

•
渐进式生长：通过对话引导 AI 对特定章节进行深度拆解，生成子分类或具体知识点。

•
标准化标注：自动识别知识点分类（事实、概念、程序、元认知）并标注重点、难点等标签。

•
系统导入支持：一键导出符合您提供的 Excel 模板格式的数据文件，支持直接导入教学系统。

•
可视化预览：提供知识结构的图形化展示，方便直观查看知识点间的逻辑关系。

使用指南

1.
AI 规划：在聊天窗口输入您的课程设想。

2.
预览：在“知识结构预览”标签页点击刷新，查看当前已生成的节点列表。

3.
导出：在“导出与图示”标签页点击导出按钮，下载生成的 Excel 文件。

4.
图示：点击生成可视化图谱，查看知识点连接情况。

技术规格

•
后端引擎：基于 LLM 的知识抽取逻辑。

•
数据格式：支持 7 级目录结构，符合主流知识图谱导入标准。

•
关系处理：自动处理前置、后置及关联关系，确保逻辑严密。
